# Автоматизоване тестування сайту Vivat

## Про проєкт
Цей проєкт створено в межах практичної роботи з дисципліни тестування програмного забезпечення. Мета — ознайомитися з автоматизованим тестуванням вебсайтів за допомогою JavaScript та Playwright.

Для тестування обрано інтернет-магазин книжок **[Vivat](https://vivat.com.ua/)**.

## Використані технології
- **JavaScript** — мова програмування.
- **Playwright** — інструмент для автоматизації тестування браузера.
- **Node.js** — середовище виконання JavaScript.

## Виконані автоматизовані перевірки
1. Перевірка відкриття головної сторінки сайту.
2. Перевірка наявності поля пошуку.
3. Виконання пошуку книги за запитом «Дракула».
4. Перевірка доступності сайту після виконання пошуку.

## Запуск тесту

1. Завантажити або клонувати репозиторій.
2. Встановити залежності:

   ```bash
   npm install
   ```

3. Встановити браузер Chromium:

   ```bash
   npx playwright install chromium
   ```

4. Запустити автоматизований тест:

   ```bash
   node vivat-test.js
   ```

## Результат
Автоматизований тест успішно запускається та виконує чотири перевірки вебсайту Vivat.
